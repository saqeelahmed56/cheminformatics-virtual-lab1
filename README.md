# Cheminformatics Virtual Laboratory

A Streamlit web app to learn SMILES, visualize molecules in 2D/3D, calculate
properties, take a quiz and download a PDF report.

Run locally:

    pip install -r requirements.txt
    streamlit run app.py

Edit the CONFIG block at the top of `app.py` (college, department, your name).
Optional: put your college logo at `logo.png`.
